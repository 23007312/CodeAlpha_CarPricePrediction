# CodeAlpha Car Price Prediction

## 📌 Project Overview
This project uses Machine Learning to predict the selling price of used cars based on features like present price, car age, kilometers driven, fuel type, and transmission.

## 📊 Dataset
The dataset used is `car data.csv`. It was cleaned to remove motorcycles and feature engineering was applied to create a 'Car_Age' column.

## 🛠️ Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (Linear Regression, Random Forest Regressor)

## 🚀 Model & Results
- **Models Used:** Linear Regression and Random Forest Regressor.
- **Best Model:** Random Forest Regressor performed better with a higher R² score.
- **Key Finding:** 'Present Price' and 'Car Age' are the most important factors affecting the selling price.

## 📁 How to Run
1. Clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook or Google Colab.
3. Ensure `car data.csv` is in the same directory.
4. Run all cells.
